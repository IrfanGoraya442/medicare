# 🏥 MEDICARE

MEDICARE is a full-stack MERN healthcare management system that allows patients to book doctor appointments and medical services online. It includes separate dashboards for Admin and Patients/Doctors, secure authentication, Stripe payment integration, and a fully responsive user interface.

## 🚀 Features

- Doctor Appointment Booking
- Medical Service Booking
- Stripe Online Payments
- Admin Dashboard
- Patient Dashboard
- Doctor Dashboard
- Doctor Management
- Service Management
- Appointment Management
- Responsive Design
- Secure Authentication
- Cloud Image Upload

## 🛠️ Tech Stack

### Frontend
- React.js

- Axios

### Admin
- React.js

### Backend

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Install dependencies

```bash
cd frontend
npm install

cd ../admin
npm install

cd ../backend
npm install
```

### 3. Configure Environment Variables

Create a `.env` file inside the `frontend`, `admin`, and `backend` folders with the required environment variables.

### 4. Start the project

Frontend

```bash
npm run dev
```

Admin

```bash
npm run dev
```

Backend

```bash
npm run start
```
